## 부제 (30자 이내)

```
틀린 풀이 사진으로 만드는 수학 오답노트
```

## 설명

```
분명히 풀 줄 아는 문제인데, 시험만 보면 또 틀리지 않나요?

오답노트가 좋은 건 다 알아요. 쓰는 게 귀찮을 뿐이죠.
다시다는 틀린 풀이를 사진으로 올리면 틀린 줄을 짚어주고, 오답노트로 남겨요. 그리고 잊을 때쯤 다시 물어봐요.

■ 사진 오답노트
• 손으로 푼 풀이를 찍거나 앨범에서 골라 올려요
• AI가 풀이를 읽고 틀린 줄을 짚어줘요
• 왜 틀렸는지 모르겠으면, 필요한 개념부터 다시 설명해줘요
• 쪽지 문제와 숫자를 바꾼 재도전으로, 진짜 알았는지 확인해요
• 갈라진 지점 · 왜 틀렸는지 · 다음엔 어떻게 — 노트가 폰 안에 쌓여 다시 볼 수 있어요

■ 복습
• AI가 약점까지 찾아낸 노트는 다음 날 홈 "오늘 복습할 것"에 떠요
• 1일 · 3일 · 7일 · 30일 간격으로 다시 물어봐요
• 알림을 켜두면 아침에 알려줘요

■ 기출 풀이
• 수능 · 평가원 모의고사 · 3월 학력평가 60회분
(고3 확률과통계 · 미적분 · 기하, 고1 · 고2 공통)
• 틀린 문제는 AI가 어디서 어긋났는지 분석해요
• 내 기록 탭에서 정답률과 자주 나온 약점을 봐요

■ 이런 학생에게 맞아요
• 오답노트가 좋은 건 아는데 귀찮아서 안 쓰는 고3 · 재수생
• 같은 유형을 자꾸 다시 틀리는 학생
```

구글과 다른 줄 (전부 1.0.10에 새로 들어간 것):
- "왜 틀렸는지 모르겠으면…" — 개념 설명(웹 09.26, 앱은 1.0.10 B부터)
- ~~"어떤 방법으로 풀었는지 AI가 못 읽으면…"~~ — 10.02 뺌(기윤 OK): 비상구 기능이라 첫 페이지에서 "못 읽는다"를 먼저 꺼낼 이유가 없다 (target-student 반응, 원문 없음)
- "노트가 남아요" → "노트가 폰 안에 쌓여 다시 볼 수 있어요" — 10.01 결론 문장
