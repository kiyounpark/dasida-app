## 08.17 검수에서 반영한 것

first-reader(12조) + 에이전트 첫 독자(수학 3등급 고3 페르소나) 결과 중 반영분.

- 제목 "1000**개**" ↔ 본문 "1000**편**" 단위 불일치 → 본문을 "개"로 통일
- ⚠️ **1편과 숫자가 어긋남 (08.17 발견)** — 1편(08.11)이 본문에서 "1,500개"를 세 번 썼는데 2편은 "1000개"였음. 6일 차이·같은 계정·예고로 이어진 후속편이라 같이 읽힘 → **1,500개로 통일.** 아침 검수(first-reader·에이전트 독자)는 둘 다 못 잡았음 — **검수가 글 하나 안만 본다**
- "오답노트도 같은 **자리**라고 봄" (내부 용어, 11조) → "똑같다고 봄"
- "이 말 **자주** 씀" (근거 1건뿐, 10조 지목) → "오르비에 이런 말도 있음"으로 하향
- 묶는 줄에 3번(한 줄로)이 안 담김 → "막힐 지점을 **한 줄로** 적으라는 거임"으로 교체
- "사진 찍으면 **끝임**" → "사진 찍으면 **오답노트가 나옴**" (에이전트가 한 박자 걸린 유일한 줄)
- 인용 중간 생략에 `(…)` 표시 (08.17) — 2024 인용이 이미 쓰는 방식과 통일

### 안 반영한 것 (지목만)

- ④ 주의 빈칸 · 엔딩 질문 없음 — 5호 "④ 늘리면 방어" 전례 + 1편 엔딩 질문 답 0건 실측 (판정 기윤)
- 링크 사라짐(각주 걷기) · 오늘 밤 행동 없음 — 각주 걷기는 3c 규칙, 본문에 연도·제목 남아 검색 가능
- **인용 3개로 줄이기 — 다섯 편 유지** (08.16 🔒 "길이 안 줄인다"). 결론의 다리가 다섯 그 자체라 셋으로 줄이면 10년 폭·조회 75,383·예고(좋아요 1등)까지 같이 무너짐
