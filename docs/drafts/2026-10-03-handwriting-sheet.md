## 1A
문제: 방정식 2^(x+1) = 4^(x−3) 의 해를 α라 할 때, log₂(α+1) 의 값을 구하시오.
```
2^(x+1) = 4^(x−3)
2^(x+1) = 2^(2x−6)
x + 1 = 2x − 6
x − 2x = −6 + 1          ⚠️ 일부러 틀린 줄
−x = −5
α = x = 5
log₂(α+1) = log₂(5+1) = log₂6
```
버릇: −6 + 1 의 + 는 또렷하게 · 2x−6 은 2 위에 작게 올려 쓰기

## 1B
문제: 함수 f(x) = x³ − 6x² + 9x + k 의 극댓값과 극솟값의 합이 10일 때, 상수 k의 값을 구하시오.
```
f'(x) = 3x² − 12x + 9
3(x − 1)(x − 3) = 0
x = 1 또는 x = 3
f(1) = 1 − 6 + 9 + k = 4 + k
f(3) = 27 − 54 + 27 + k = k
(4 + k) + k = 10
2k = 10 + 4              ⚠️ 일부러 틀린 줄
k = 7
```
버릇: 27 − 54 + 27 + k 는 빽빽하게 붙여 쓰기 · 마지막 7에 가로줄 긋기(유럽식 7)

## 2A
문제: 함수 f(x) = 2x³ + 3x² − 12x + 1 의 극댓값을 구하시오.
```
f'(x) = 6x² + 6x − 12
f'(x) = 6(x + 2)(x − 1)
x = −2 에서 극대
f(−2) = 2×(−8) + 3×4 − 12×(−2) + 1
= −16 + 12 − 24 + 1      ⚠️ 일부러 틀린 줄
= −27
```
버릇: −12×(−2)의 괄호 안 마이너스를 2에 바짝 · −24의 마이너스를 짧고 살짝 위로

## 2B
문제: 수열 {aₙ}이 a₁ = −3 이고 모든 자연수 n에 대하여 aₙ₊₁ = −2aₙ + 1 을 만족시킬 때, a₄의 값을 구하시오.
```
a₂ = −2a₁ + 1
a₂ = −2×(−3) + 1 = 6 + 1 = 7
a₃ = −2×7 + 1 = 14 + 1   ⚠️ 일부러 틀린 줄
a₃ = 15
a₄ = −2×15 + 1 = −30 + 1
a₄ = −29
```
버릇: −2×7의 ×를 작게 써서 x처럼 보이게

## 3A
문제: 등차수열 {aₙ}에서 a₂ = 7, a₅ = 19일 때, a₁ + a₂ + a₃ + … + a₁₀ 의 값을 구하시오.
```
a₅ − a₂ = 3d
19 − 7 = 3d,  d = 4
a₁ = 7 − 4 = 3
S₁₀ = 10{2×3 + 10×4} / 2   ⚠️ 일부러 틀린 줄
= 5 × 46
= 230
```
버릇: 중괄호 { }를 둥근 괄호처럼 · a₅, a₂ 아래첨자를 작게 붙여 쓰기

## 3B
문제: 함수 f(x) = (x² + a)(x − 1)에 대하여 f(2) = 7일 때, f'(2)의 값을 구하시오. (단, a는 상수)
```
f(2) = (4 + a)(2 − 1) = 7
4 + a = 7
a = 3
f(x) = (x² + 3)(x − 1)
f'(x) = 2x × 1           ⚠️ 일부러 틀린 줄
f'(2) = 2 × 2 = 4
```
버릇: f'(x)의 '를 짧게 써서 f(x)와 헷갈리게

## 4A
문제: 곡선 y = x² − 2x 와 x축 및 두 직선 x = 0, x = 4 로 둘러싸인 부분의 넓이를 구하시오.
```
x² − 2x = x(x − 2)
x(x − 2) = 0 → x = 0 또는 x = 2
S = ∫₀² (x² − 2x)dx + ∫₂⁴ (x² − 2x)dx      ⚠️ 일부러 틀린 줄
∫₀² (x² − 2x)dx = [x³/3 − x²]₀² = 8/3 − 4 = −4/3
∫₂⁴ (x² − 2x)dx = (64/3 − 16) − (8/3 − 4) = 16/3 + 4/3 = 20/3
S = −4/3 + 20/3 = 16/3
```
버릇: −4/3의 마이너스를 분수선과 비슷한 길이로 짧게 · 적분 구간 숫자를 작게 흘려 쓰기

## 4B
문제: 방정식 log₂(x − 1) + log₂(x + 2) = 2 의 모든 실근의 합을 구하시오.
```
log₂{(x − 1)(x + 2)} = 2
(x − 1)(x + 2) = 4
x² + x − 2 = 4
x² + x − 6 = 0
(x + 3)(x − 2) = 0
x = −3 또는 x = 2
실근: x = −3, x = 2      ⚠️ 일부러 틀린 줄
합 = −3 + 2 = −1
```
버릇: log₂의 2를 작게 써서 log 옆 숫자처럼

## 5A
문제: 함수 f(x) = x³ − 3x² − 9x + 5 의 극솟값을 구하시오.
```
f'(x) = 3x² − 6x − 9
3x² − 6x − 9 = 0
x² − 2x − 3 = 0
(x − 3)(x + 1) = 0
x = −1 또는 x = 3
f(3) = 27 − 27 − 27 + 5 = −22
답: 3                    ⚠️ 일부러 틀린 줄
```
버릇: −22의 마이너스를 22에 바짝 붙여 짧게

## 5B
문제: 등차수열 {aₙ}에서 a₂ = 5, a₆ = 17일 때, a₁ + a₁₀ 의 값을 구하시오.
```
a₆ − a₂ = 4d
17 − 5 = 4d
d = 3
a₁ = a₂ − d = 5 − 3 = 2
a₁₀ = a₁ + 9d = 2 + 27 = 29
답: 29                   ⚠️ 일부러 틀린 줄
```
버릇: a₆, a₁₀ 아래첨자를 본문 글자랑 거의 같은 크기로

## 6A — 전부 맞게 푼 풀이
문제: 함수 f(x)=x³−3x²−9x+2 의 극솟값을 구하시오.
```
f'(x)=3x²−6x−9

```
버릇: 마지막 줄에 처음엔 **−23**이라고 쓰고, 두 줄 그은 뒤 바로 옆에 −25 · x=−1, =−25의 마이너스는 숫자에 바짝

## 6B — 전부 맞게 푼 풀이
문제: 등차수열 {aₙ}에서 a₃=−4, a₇=−16 일 때, a₁₂의 값을 구하시오.
```
a₇−a₃=4d
−16−(−4)=4d
4d=−12
d=−3
a₁=a₃−2d=−4+6=2
a₁₂=a₁+11d=2+11×(−3)
a₁₂=−31
```
버릇: d=−3 줄에 처음엔 **d=3**(마이너스 없이)이라고 쓰고, 3에 두 줄 그은 뒤 옆에 −3 · =−12, =−31의 마이너스는 숫자에 바짝
