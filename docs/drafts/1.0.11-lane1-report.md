- **"같은 선택 재전송"을 어떻게 읽을지.** 약속 파일은 "같은 선택 재전송 = 시각 안 바꿈 · version은 보낸 판으로"라고만 적혀 있다. 나는 "같은 답 + 같은 판"일 때만 시각을 유지하게 했다. 문구 판이 올라 다시 켜면 새 동의로 보고 `agreedAt`을 새로 찍는다(`nextConsentEntry`). 판이 올라도 옛 `agreedAt`을 유지하는 게 의도였다면 `save-consent.ts` 한 줄만 바꾸면 된다. 판을 올리는 일 자체가 아직 없어서 지금 동작에는 차이가 없다.
- 실제 기기에서 온보딩 직후 홈이 비치는지, 비친다면 얼마나 오래인지.
- 같은 계정으로 다시 로그인할 때 로그인 화면에 얼마나 머무는지. 로그아웃이 사본을 지우므로 서버를 기다리고, 상한은 6초다.
- `getRemoteAuthHeaders`가 토큰을 못 받아 계정 키만 보내는 경우. 서버가 401을 주고 [다음]이 실패한다(오류 줄). 실기기에서 얼마나 자주 일어나는지는 모른다.
- 1차 배포 7분 사이에 익명 요청이 실제로 있었는지(위 배포 이력).

## 합칠 때 부딪힐 것 같은 자리

- `features/consent/consent-store.ts`: 머리 주석을 고쳤고 `isConsentDocLike`를 export했다. `clearLocalConsent`는 안 던진다. `readLocalConsent`·`writeLocalConsent`의 시그니처는 그대로다.
- `features/analytics/event-types.ts`: `EventName`·`EventParams` 끝에 더했다. 다른 줄이 이벤트를 더했으면 같은 끝줄에서 텍스트 충돌이 날 수 있다.
- `functions/src/get-consent.ts`의 `readConsentDoc`: 2줄이 동의 읽기 도우미를 따로 만들었으면 하나로 합치는 게 좋다.
- `features/auth/firebase-auth-client.ts` `deleteAccount`의 `Promise.all`: 다른 줄이 같은 자리에 지우기를 더했으면 충돌할 수 있다(표상 1줄 담당).
- main `.expo/types` 재생성: 「결론 먼저」 2.

## 스토어 신고에서 바꿀 답 목록 (기윤 몫 — 콘솔 일)

지금 콘솔에 뭐라고 답해 놨는지는 확인 안 했다. 아래는 1.0.11에서 **사실이 바뀌는 자리**다.

**구글 Play — 데이터 보안(Data safety)**
1. **사진(Photos and videos → Photos)**: "수집함"으로 답한다. 이제 노트와 함께 계정에 저장되니 "일시적 처리(ephemeral)"로는 못 뺀다. 목적은 앱 기능이다.
2. **기타 사용자 생성 콘텐츠(App activity → Other user-generated content)**: 오답노트 내용(틀린 지점·약점 유형·처방)이 계정에 저장된다. 수집함, 앱 기능.
3. **[선택] 검토용 사진**: 같은 "사진" 항목에 목적 하나가 더 붙는다. 정확도 개선이고, 콘솔 선택지로는 "분석(Analytics)"이 가장 가까워 보인다. 판단 필요.
4. **필수/선택 질문**("이 데이터 수집이 필수인가요?"): 사진·노트는 필수 동의 없이 앱을 못 쓰니 "필수"에 가깝다. 다만 사진 기능을 안 쓰면 실제로 수집되지 않는다. 어느 쪽으로 답할지는 기윤이 정할 것.
5. **공유**: OpenAI 전송은 이미 신고돼 있을 것이다. 서비스 제공자 처리로 본다면 "공유"가 아니다. 지금 답을 확인할 것.
6. **삭제 요청 가능**: 앱 안의 계정 삭제로 노트·사진·검토본·동의 기록이 지워진다(검토본 지우기는 2줄 탈퇴 코드가 합쳐져야 참이 된다). "예" 유지.

**애플 — 앱 개인정보 라벨(App Privacy)**
1. **사진 또는 동영상(Photos or Videos)**: "수집함", **사용자와 연결됨**(계정에 저장). 목적은 앱 기능. 이전에는 실시간 처리만이라 "수집 안 함"으로 답했을 수 있다. 그랬다면 바꿔야 한다.
2. **기타 사용자 콘텐츠(Other User Content)**: 오답노트 내용. 수집함, 사용자와 연결됨, 앱 기능.
3. **[선택] 검토용 사진의 목적**: "분석(Analytics)"이나 앱 기능 개선 중에서 고를 것. 판단 필요.
4. **추적(Tracking)**: 바뀌는 것 없음.

방침(`public/privacy/index.html`)과 라벨이 같은 말을 해야 한다. 방침은 hosting에 배포해야 웹에 반영된다.
