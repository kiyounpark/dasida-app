## 스토어 신고에서 바꿀 답 목록 (기윤 몫 — 콘솔 일)

지금 콘솔에 뭐라고 답해 놨는지는 확인 안 했다. 아래는 1.0.11에서 **사실이 바뀌는 자리**다.

**구글 Play — 데이터 보안(Data safety)**
1. **사진(Photos and videos → Photos)**: "수집함"으로 답한다. 이제 노트와 함께 계정에 저장되니 "일시적 처리(ephemeral)"로는 못 뺀다. 처리 목적은 앱 기능이다.
2. **기타 사용자 생성 콘텐츠(App activity → Other user-generated content)**: 오답노트 내용(틀린 지점·약점 유형·처방)이 계정에 저장된다. 수집함, 앱 기능.
3. **[선택] 검토용 사진**: 같은 "사진" 항목에 목적 하나가 더 붙는다(정확도 개선 — 콘솔 선택지로는 "분석(Analytics)"이 가장 가까워 보인다. 판단 필요).
4. **필수/선택 질문**("이 데이터 수집이 필수인가요?"): 사진·노트는 필수 동의 없이 앱을 못 쓰니 "필수"에 가깝다. 다만 사진 기능을 안 쓰면 실제로 수집되지 않는다. 어느 쪽으로 답할지는 기윤이 정할 것.
5. **공유**: OpenAI 전송은 이미 신고돼 있을 것이다. 서비스 제공자 처리로 본다면 "공유" 아님. 지금 답을 확인할 것.
6. **삭제 요청 가능**: 앱 내 계정 삭제로 노트·사진·검토본·동의 기록이 지워진다(검토본 지우기는 2줄 탈퇴 코드가 합쳐져야 참). "예" 유지.
