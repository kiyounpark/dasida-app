## H1A
문제: csat-2024 13번 (그림은 Claude가 붙여요)
```
f(x)=(x−1)(x−2)(x−c)
f'(0)=2c+c+2=−7
c=−3, f(x)=x³−7x+6
f(3)=12, OP: y=4x
B−A=∫₀³(4x−f(x))dx
∫₀³f dx=∫₀¹f dx−∫₁²f dx+∫₂³f dx   ⚠️ 일부러 틀린 줄
∫₀¹f dx=11/4, ∫₁²f dx=−3/4
∫₂³f dx=19/4
∫₀³f dx=11/4+3/4+19/4=33/4

B−A=18−33/4=39/4
39/4 ②
```
버릇: 6번 줄 ∫₁²f dx 앞의 −를 짧게 써서 ∫ 머리에 바짝 붙인다 · 3번 줄 x³의 ³을 작게 올려 써서 x3처럼 보이게 한다

## H2A
문제: csat-2025 20번 (그림은 Claude가 붙여요)
```
aₙ₊₁ = 2/3(aₙ₊₁−aₙ) + (가)
(가) = 1/6{(n+1)² − n²} − 1/6
= (2n+1)/6 − 1/6 = n/3 = f(n)
2aₙ + aₙ₊₁ = n
f(12) = 12/3 = 4
2a₂ₖ₊₁ + a₂ₖ₊₂ = 2k+1
Σ(2k+1) = 3+5+7+9+11 = 35
n=2: 7+a₂ = 2/3a₂+4/6−2/6+10
7 + a₂ = 2/3a₂ + 31/3
1/3a₂ = 31/3 + 7                ⚠️ 일부러 틀린 줄
1/3a₂ = 52/3 → a₂ = 52 = p
q = 7 + 52 + 35 = 94

```
버릇: 10번 줄 1/3a₂의 1/3을 a₂에 바짝 붙여 써서 한 덩어리처럼 보이게 쓴다 · 13번 줄 52×94의 ×를 작게 기울여 x처럼 흘려 쓴다

## H2B
문제: csat-2024 20번 (그림은 Claude가 붙여요)
```
(1/5)ᵏ⁻³ = k → 5³⁻ᵏ = k
log₅k = 3 − k
t = 1/(k³×5³ᵏ)
log₅t = −3log₅k − 3k
= −3(3 − k) − 3k
= −9 + 3k − 3k = −9 → t = 5⁻⁹
x > k : f(x) = 5³⁻ˣ, f(f(x)) = 3x
5³⁻ˣ = 5⁻⁹
3 − x = −9
−x = −9 + 3 = −6                    ⚠️ 일부러 틀린 줄
x = 6
f(5⁻⁹) = f(f(6)) = 3×6 = 18
```
버릇: 6번 줄 5⁻⁹의 지수 마이너스를 9에 바짝 붙여 작게 쓴다 · 9번 줄 3 − x의 x를 ×에 가깝게 흘려 쓴다

## H3A — 전부 맞게 푼 풀이
문제: csat-2024 9번 (그림은 Claude가 붙여요)
```
f(x)=3x²−16x−20
F(x)=x³−8x²−20x
F(−2)=−8−32+40=0
F(0)=0
∫₋₂⁰ f(x)dx=F(0)−F(−2)=0
∫₋₂ᵃ f(x)dx=F(a)−F(−2)=F(a)
F(a)=0
a³−8a²−20a=0
a(a²−8a−20)=0
a(a−10)(a+2)=0
a=−2, 0, 10
a>0 → a=10  ④
```
버릇: 2번 줄에서 −8x² 자리에 처음 −16x²를 쓰고 두 줄로 그은 뒤 바로 옆에 −8x²를 다시 쓴다 · 3번 줄 =−8−32의 −8 마이너스를 =와 8에 바짝 붙여 쓰고, 11번 줄 a=−2도 −를 2에 붙여 쓴다

## H3B — 전부 맞게 푼 풀이
