## 모르는 것

1. **운영 함수 서비스 계정의 Storage 권한.** 2세대 함수 기본 계정(Compute 기본 계정)은 보통 프로젝트 편집자라 될 것 같다 — 같은 계정으로 Firestore를 이미 쓰고 있다. 그래도 직접 확인은 안 했다. 없으면 탈퇴가 전부 500(학생 계정이 안 지워짐), 저장은 500. 확인하려면 GCP 콘솔 IAM에서 `…-compute@developer.gserviceaccount.com`에 편집자(또는 Storage 객체 관리자)가 있는지 보거나, 첫 실제 탈퇴의 로그를 본다.
2. `getStorage().bucket()`이 운영에서 `dasida-app.firebasestorage.app`을 가리키는지 — lanes 문서 전제를 믿었고 직접 안 봤다.
3. 원장 `accountKey == ∧ submissionId ==` 두 칸 같음 쿼리가 복합 색인 없이 도는지. 실패하면 첫 검토본 찾기만 빠지고 오늘 경로로 간다(테스트로 묶음) — 동의한 학생만 해당.
