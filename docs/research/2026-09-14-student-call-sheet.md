# 학생 통화 관찰지 (30분 · 웹 dasida-proto.netlify.app)

날짜: ____  학생: ____ (고3 / 재수)  기기: 아이폰 / 안드  통화 시작: __:__

목적: **사진 → 오답노트 사이에서 새는 자리 하나 찾기.** 쇼츠 0초 이탈 원인은 이 통화로 안 잡힌다 (약속하고 온 학생은 0초에 안 나간다) — 첫 화면에 매달리지 말 것.

준비: 전날 카톡 "최근 틀린 수학 문제, 풀다 만 흔적 있는 거 한 장 옆에 두세요." 없다면 문제 1개 보내서 종이에 풀고 채점까지. 주소는 통화 시작 후에 보낸다.
준비 결과: 본인 문제 있음 / 없어서 보낸 문제 씀 / 답만 체크된 것  ← "없음" 자체가 첫 관찰 결과

## 0. 시작 2분 — 이 말만
- "시간 내줘서 고마워요. 앱 소개하려는 거 아니고, 어디서 막히는지 보려는 거예요."
- "잘 안 되는 데 찾는 거라, 막히면 막힌다고 그대로 말해주세요. 그게 제일 도움 돼요."
- "제가 옆에서 알려주면 뭐가 헷갈리는지 제가 못 봐요. 그래서 물어봐도 되는데, 제가 바로 답 안 하고 잠깐 기다릴 거예요. 무시하는 거 아니에요."
- 화면 공유 켜기 → 주소 카톡으로 전송 → "열어보세요." 끝. 여기서부터 입 닫는다.

## 1. 시킬 것 (설명 없이, 이 말만)
1. "링크 열어보세요." → 첫 화면 보는 동안 아무 말 안 함 (10초 셈)
2. (학생이 뭘 할지 모르면 15초 기다린 뒤) "하고 싶은 대로 해보세요."
3. 사진 올렸으면 → 아무 말 안 함. 분석 15초 동안 말·한숨·침묵, 화면 딴 데로 넘기나 기록
4. 채팅 질문 나오면 → "편하게 답해보세요." 이후 개입 없음
5. 오답노트 카드 나오면 → "다 봤으면 말해주세요." (읽는 시간 셈)

## 3. 절대 하지 말 것
- 설명하기 ("이건 이렇게 쓰는 거예요") — 막혀도 15초는 기다린다
- 변명하기 ("아 그건 아직 미완성이라") — "네, 적었어요"로 끝
- "이거 좋죠?" / "괜찮죠?" 묻기 — 답이 오염된다
- 돈 낼 거냐고 묻기
- 학생 말 끊고 요약하기 — 그대로 받아 적는다

## 4. 마지막 5분 — 질문 3개 (이 순서)

2. "내일 또 틀린 문제 생기면 뭐 할 것 같아요?" (여기 올린다는 말이 먼저 나오면 진짜, 안 나오면 그것도 답)
3. "오답노트 카드 보고 든 생각 하나만요."
