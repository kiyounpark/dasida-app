### 알게 된 것 (10.07)

- 우리와 같은 꼴(유명 기출 + 풀이) 채널들의 **평소** 쇼츠가 1,000~3,000회 — 우리 9호 196회의 5~15배. 소재 종류가 아니라 첫 3초·제목에서 갈릴 것 같다(짐작).

### 다시 모을 때 (레시피)

- 이 맥은 `/etc/hosts`에 youtube.com이 막혀 있다(기윤 환경 잠금 — 안 푼다) → 수집은 Apify(클라우드). 무료 등급 크레딧에서 빠진다(잔액은 콘솔에서 확인).
- 검색: `streamers/youtube-scraper` — `searchQueries`, `maxResultsShorts: 30`, `maxResults: 0`, `dateFilter: "year"` · 쇼츠 1개 $0.004 · 검색어 하나 ≈ $0.12.
- 단발 확인: `streamers/youtube-shorts-scraper` — `channels`, `maxResultsShorts: 10`, `sortChannelShortsBy: "NEWEST"`.
- 받기: `streamers/youtube-video-downloader` — `storeInKVStore: true` · 1MB $0.006 · **결제 상한 최소 $0.50** · 480p를 청해도 240×426으로 옴(글씨는 읽힘) · Apify 저장소 파일은 ~3일 뒤 삭제 → `curl`로 받기(샌드박스 밖).
- 프레임: `ffmpeg -t 3 -i in.mp4 -vf "fps=4,scale=200:-1,tile=6x2"` (첫 3초 12장) · `fps=1/3,…,tile=8x3` (전체).
- 두 모델: astra는 측정 폴더(git 아님)에서 `codex exec --skip-git-repo-check … -i 사진`, Fable은 Agent로 사진을 Read하게. 갈리면 Fable 2차.
- 「공부법」 검색은 쇼츠 0개였다(원인 안 봄).
