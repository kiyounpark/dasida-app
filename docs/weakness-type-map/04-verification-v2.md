## 반박 성공 (6건)

- **삼각방정식 범위 오류** (`g2_trig_equation_range`) | 개념 → **마무리**
  근거: desc `"삼각방정식의 해를 구할 때 주어진 각도 범위를 벗어난 해를 포함하거나 누락했습니다."` / tip `"단위원에서 조건을 만족하는 각도를 모두 찾은 뒤, 범위에 해당하는 것만 선택하세요."`
  이유: 범위는 **문제에 주어져 있다**(desc가 "주어진"이라고 씀). 해를 다 구해놓고 마지막에 거르는 단계를 빼먹은 것이라 다시 읽으면 잡힌다 — v2가 적은 "범위 자체를 모르는 학생"이라는 근거는 desc·tip 어디에도 없다. (절차도 대안이나, tip이 "모두 찾은 뒤 → 선택"의 마지막 단계를 가리키므로 마무리가 더 맞음)

- **평면기하** (`g1_geometry`) | 공식 → **개념**
  근거: 학생 문장 3개 중 2개가 `"피타고라스 정리를 어떤 삼각형에 적용할지 몰랐어요."` / `"보조선을 어디에 그어야 할지 몰랐어요."`
  이유: a²+b²=c²을 못 외운 게 아니라 어디에 쓸지를 모르는 것. "공식을 손으로 세 번 써보자"가 헛돈다. tip의 동사도 `"직각삼각형을 찾거나 보조선으로 만들어"`로 암기가 아니다. v2 자신이 나머지정리·경우의 수에는 같은 문형("어디에 어떻게 쓰는지")을 개념으로 판정했다.

- **적분 계산** (`g3_integral`) | 공식 → **개념**
  근거: 학생 문장 3개 전부 `"치환적분·부분적분을 어디에 써야 할지 몰랐어요."` / `"정적분으로 넓이 계산할 때 절댓값 처리가 어려웠어요."` / `"∫f(t)dt를 미분하는 관계식 활용이 막혔어요."`
  이유: 계산 실수 문장이 하나도 없고 전부 "언제/어떻게 쓰는지 모름". 치환적분 공식을 세 번 써도 언제 쓸지는 안 잡힌다. v2가 `g2_poly_remainder`를 "어디에 어떻게 쓰는지 → 언제 쓰는지를 모름 → 개념"으로 판정한 것과 기준이 어긋난다.

- **중복 계산 오류** (`g2_counting_overcounting`) | 절차 → **공식**
  근거: tip 전문 `"포함-배제 원리: n(A∪B) = n(A)+n(B)-n(A∩B). 겹치는 케이스를 명시적으로 표시하세요."`
  이유: v2 근거란은 "tip이 포함-배제 원리 적용 **순서**"라고 적었는데 tip에는 순서·단계가 없다. 공식 한 줄이 전부다. 대조군 `g2_set_count`의 tip은 `"n(A∩B)를 먼저 구하고, 중복된 원소를 딱 한 번만 빼는지 확인"`으로 순서가 실제로 있다. 덤으로 이걸 고치면 경우의 수 절차 2중 충돌이 풀린다.

- **인수분해 패턴 누락** (`g2_poly_factoring`) | 공식 → **절차**
  근거: tip `"상수항의 약수를 대입해 근을 찾고, 조립제법으로 인수를 하나씩 꺼내는 흐름을 연습하세요."`
  이유: 처방이 암기가 아니라 흐름이다. 대조군 `factoring_pattern_recall`의 tip은 `"공식(합차, 완전제곱 등)을 반복해서 쓰고 외워보세요"`로 진짜 공식이다. 고차 인수분해에는 외울 공식이 아니라 인수정리→조립제법이라는 단계가 있을 뿐인데 "공식을 손으로 세 번 써보자"가 나간다.

- **무리식 간소화 오류** (`g2_radical_simplify`) | 계산 → **공식**
  근거: desc `"√a·√b = √(ab), √(a²) = |a| 등 무리식 간소화 규칙을 잘못 적용했습니다."`
  이유: √(a²)=|a|를 틀리게 알고 있는 학생에게 "한 단계 한 줄로 끊어 쓰자"는 소용없다. 대조군 `radical_simplification_error`의 desc는 `"제곱근 안의 수를 인수분해해 간소화하는 단계에서 오류"`로 규칙이 아니라 수행이라 계산이 맞는데, v2는 둘을 같은 태그로 묶었다. 이 약점은 08.02에 선택지가 삭제돼 학생 문장이 없어 desc/tip만이 근거다.
