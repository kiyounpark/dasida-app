## 구조 문제 (태그 하나짜리 문제가 아님)

한 풀이법 안에서 같은 태그가 겹치면 AI가 유형을 말해도 약점을 못 고른다. 초안 태그 그대로 계산한 충돌:

- `radical`(무리수): **계산 5중 충돌** — √ 간소화 실수 / 분모 유리화 실수 / 계산 실수 반복 / 무리식 간소화 오류 / 유리화 계산 오류
- `polynomial`: 계산 3중 — 전개 부호 실수 / 동류항 정리 실수 / 계산 실수 반복
- `proposition`(명제): **개념 3중** — 역·이·대우 혼동 / 필요충분조건 오류 / 전칭·존재 명제 혼동. 태그로 아무것도 못 가림
- `counting`: 세우기 2중 + 절차 2중 (고1판·고2판이 사실상 같은 약점)
- `quadratic`, `complex_number`, `remainder_theorem`, `set`: 각각 계산 2중

`radical`·`counting`의 중복은 태그 문제가 아니라 약점 목록에 같은 게 두 벌 들어있는 것이다(무리식 간소화 오류 ≈ √ 간소화 실수, 유리화 계산 오류 ≈ 분모 유리화 실수, 경우의 수 방법 선택 오류 ≈ 경우의 수 방법 혼동, 중복 계산 오류 ≈ 중복 처리 실수, 미분 활용 오류 ≈ 풀이 순서 혼동). 통역표를 고쳐도 이건 안 없어진다.
