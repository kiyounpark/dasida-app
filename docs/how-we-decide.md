# 결정은 어떻게 내리나 — astra · Fable

> 🔒 2026.09.20 기윤 결정. **다른 채팅방에서도 이 파일 하나만 읽으면 된다.**
> Claude 메모리에도 요약본이 있지만(`feedback-decide-with-astra-and-fable`),
> 메모리는 Claude만 읽는다. 어긋나면 **이 파일이 정본**이다.

## 한 줄

**Claude 혼자 정하지 않는다. astra와 Fable 둘에 걸고, 갈리면 Fable이 최종으로 정한다.**

## 왜

09.19에 Claude 혼자 내린 판단이 두 번 연속 틀렸다.

1. "처방(tip)은 복습에서만 뜬다" → 실제로는 기출 진단·퀴즈 결과에도 뜬다
2. "이름은 학생 눈, 처방은 수학 눈" 규칙 → 근거가 무너져 폐기

두 모델을 걸었더니 Claude가 몰랐던 사실이 나왔다 — 약점 59개 전부 `heroPrompt`가 있어서
tip 폴백은 한 번도 안 켜진다.

> **한 모델의 결론은 그 모델이 안 본 코드만큼 약하다.**

## 순서 🔒

```
1. astra + Fable 둘에게 같은 질문을 건다
2. 답이 갈리면 → Fable에게 astra 답을 통째로 주고 다시 정하게 한다
3. Fable이 정한 대로 간다
4. astra 한도가 부족해지면 그때 다시 정한다
```

**2번 프롬프트에 이 문장을 매번 넣는다:**

> 네 안을 방어하지 마라. astra 안이 나으면 그걸로 가도 된다. 버려도 된다.

09.20에 실제로 Fable이 astra 답을 보고 자기 안을 버렸다. 이 문장이 없으면 자기 안을 지킨다.

**왜 Fable이 최종인가** — 기윤이 정했다. astra만 ChatGPT 한도를 먹고, 셋을 다 돌리면 한도가
안 버틴다. Fable은 Claude 구독 안에서 돈다.

⚠️ **Claude가 먼저 추천을 내지 않는다** (09.19). 재료(대조표·계산·코드 확인)는 만들되
"추천은 ○○"는 **두 모델 답이 온 뒤에만** 쓴다.

## 기윤한테 올리는 것 — 셋뿐 🔒

09.20에 기윤이 말했다 — *"솔직히 이유만 봐도 나는 잘 모르는데 그것도 너가 판단해주면 안됩니까?"*

기윤이 정하고 싶은 건 **방향**인데 Claude가 올린 건 **방법**이었다.
방법을 판단하려면 그 밑의 층을 다 알아야 한다.

**올리는 것:**

1. **학생한테 가는 게 바뀔 때** — 화면에 뜨는 것, 학생이 받는 것
2. **돈·시간이 크게 들 때**
3. **되돌리기 비쌀 때** — DB 스키마, 데이터 구조, API 계약

**셋 다 아니면 Claude가 정하고 보고만 한다.** 묻지 않는다.

⚠️ **올리기 전에 "이미 정해진 것 아닌가"를 먼저 찾는다.**
09.20에 말풍선을 "만들까 말까"로 기윤에게 물었는데, 08.11에 이미 🔒로 정해져 있었다.
잠근 걸 다시 연 것이다. `docs/` 안에서 🔒를 먼저 grep한다.

## 누가 무엇을 하나 🔒

| 자리 | 누구 | 부르는 법 |
|---|---|---|
| **판단·결정** | **astra** + **Fable** → Fable 최종 | 아래 |
| **만들기** | **Opus** (`weakness-author`) | Agent 툴 · `model: opus` |
| **검산** | **sol** `high` (`math-checker`) | `scripts/call-math-checker.sh` |
| **문구 린트** | **Haiku** (`target-student`) | Agent 툴 · `model: haiku` |
| **숫자 확인** | **Claude가 코드로 직접** | — |

**`xhigh`는 안 쓴다.**

⚠️ **모델이 숫자를 말하면 Claude가 예외 없이 직접 센다.** `몇 건`·`몇 %`·`어디에 있다`는 전부
확인 대상이다. 09.20에 Fable이 "선택지 중복 4건"이라고 했는데 세어 보니 **0건**이었다.
astra가 "121쌍 중 120"이라고 한 것도 실제로는 **110**이었다.

## 부르는 법

### Fable

`Agent` 툴 · `model: "fable"` · `run_in_background: true`.
**저장소 파일을 직접 읽게 시킨다** — 요약해서 주면 요약만큼만 본다.

### astra

```bash
codex exec "<프롬프트>" -c 'model="gpt-6-astra"' -C "$PWD" -s read-only < /dev/null
```

⚠️ 기윤의 `~/.codex/config.toml`은 `[mcp_servers.notion]`·`[stitch]`에 `command`가 없어
**CLI가 시작을 거부한다.** 임시 홈으로 우회한다:

```bash
TMP="$(mktemp -d)" && chmod 700 "$TMP"
cp ~/.codex/auth.json "$TMP/auth.json"
printf 'model = "gpt-6-astra"\n' > "$TMP/config.toml"
CODEX_HOME="$TMP" codex exec "<프롬프트>" -C "$PWD" -s read-only < /dev/null
```

`scripts/call-math-checker.sh`가 이 우회를 이미 하고 있다 — 검산은 그 스크립트를 쓴다.

### 둘 다 지킬 것

- **같은 프롬프트**를 준다
- **코드 근거(파일:줄)를 요구한다.** 근거 없는 답은 Claude 혼자 판단한 것과 값이 같다
- **모델을 바꾸면 기윤에게 말한다.** 답을 전할 때 **어느 모델이 말한 건지 같이 적는다.**
  09.19에 astra→sol로 조용히 바꿨다가 "누가 한 말이냐"로 혼선이 났다
- 실제로 어느 모델이 돌았는지는 **codex stderr의 `model:` 줄**로 확인한다. 짐작하지 않는다

## 토큰

**astra만 ChatGPT 한도를 먹는다.** Fable은 기윤 Claude 구독 안에서 돈다.

호출 하나에 **4~10만 토큰**. 09.19~20 이틀에 astra **14회 · 약 79만 토큰**.

**판이 끝날 때마다 사용량을 적어 기윤에게 보고한다.** 그래야 기윤이 "부족한지"를 눈으로 본다.
부족하다고 느끼면 기윤이 그때 순서를 바꾼다 — 그게 위 「순서」의 4번이다.
